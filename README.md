# 壁纸小助手

一个 Windows 桌面小工具：从必应每日精选、360 壁纸或 Picsum 摄影抓取壁纸，按屏幕尺寸保存到本地，一键设为桌面背景。

界面用 Python 自带的 tkinter 写成，**不需要安装任何第三方库**。

## 功能

| 功能 | 说明 |
|---|---|
| 多来源可选 | 界面里切换「必应每日精选」「360 壁纸（4K）」「Picsum 摄影」，选择自动记住 |
| 按尺寸抓取 | 可选 1080P / 4K / 1366×768 / 720P 四档，自动匹配当前屏幕；Picsum 按所选尺寸裁切，360 有小尺寸就用小尺寸、没有则取原图 |
| 批量抓取 | 必应可回溯最近 1–8 天；Picsum 与 360 随机取图，不重复 |
| 跳过已下载 | 已存在的图不再重复下载 |
| 一键换桌面 | 调用 Windows 系统接口设置桌面背景，也可勾选"抓完自动设为桌面" |
| 程序内定时 | 可选 30 分钟 / 1 小时 / 6 小时 / 每天，运行期间自动抓取 |
| 自定义保存位置 | 可改目录，设置写入 `设置.json`，下次打开自动恢复 |
| 运行日志 | 界面内显示，同时追加到 `运行记录.txt` |

## 运行要求

- **Windows**（依赖 `ctypes.windll` 调用系统接口，macOS / Linux 上无法运行）
- Python 3.8 及以上（开发验证版本 3.12）
- 无需 `pip install`，只用标准库：`tkinter`、`urllib`、`json`、`threading`、`ctypes`

## 怎么用

1. 安装 Python 3.8+（安装时勾选 **Add Python to PATH**）
2. 下载本项目到本地
3. 在项目目录打开终端，运行：

```
python 壁纸小助手_界面版.py
```

4. 选壁纸来源、屏幕尺寸和数量 → 点「立即抓取一次」
5. 想换桌面就点「把最新一张设为桌面」

## 目录结构

```
壁纸小助手_界面版.py    主程序（带界面）
壁纸小助手_v3.py        命令行版，含网络重试与跳过重复
壁纸小助手_v2.py        命令行版，支持批量下载
壁纸小助手.py           最初的最小版本，只下当天一张
壁纸/                   抓取的图片（运行后生成，默认在程序同级目录）
设置.json               用户设置（运行后生成）
运行记录.txt            运行日志（运行后生成）
```

后三个 `.py` 是逐步迭代的过程留档，功能被主程序覆盖，可删除。

## 已知限制

| 限制 | 原因 |
|---|---|
| 必应尺寸只有四档，没有 2560×1440 | 必应接口只提供固定后缀，实测 `_2560x1440.jpg` 返回 404 |
| 必应一次最多 8 张 | 必应每日归档接口最多返回 8 天数据，选更大数字实际仍只给 8 条 |
| Picsum 的图没有日期和标题 | 该接口随机给图，不带元信息，文件名用图片 id 区分 |
| Picsum 单张可能要等几秒 | 大尺寸需服务端现场裁切，实测 4K 单张 5–10 秒，属正常 |
| 360 固定取「4K 专区」 | 4K 专区全部为 3840×2160，单张 1–1.5MB；想换分类改代码里的 `W360_CID`（9=风景、6=美女、26=动漫等，共 18 类） |
| 360 没有 1920 / 1280 两档小图 | 该接口只提供 1600×900、1440×900、1366×768、1280×800、1024×768 五种小尺寸，其余情况直接给 4K 原图 |
| 定时需程序保持运行 | 定时由程序内部的 `after` 实现，窗口关闭即停止。不依赖系统计划任务 |
| 仅 Windows | 换壁纸走 Windows 专用接口 |
